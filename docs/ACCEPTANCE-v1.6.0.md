## 一、v1.5.0 天气批(双端)

### 昼夜节律
- [ ] 白天鸟更活跃、夜里收敛(夜里多站立/睡觉,少飞扑)
  怎么验:白天观察 10 分钟;夜里(或把系统时间看成晚上)再观察对比。
- [ ] 夜晚会打瞌睡(zzz 特效),点一下能吵醒
  怎么验:夜里看 zzz;点击鸟。

### 天气联动(默认关)
- [ ] 设置窗有「天气联动」区:开关/城市/数据源/Key/Host/状态行
  怎么验:托盘菜单 → 设置… → 拉到天气联动区。
- [ ] 默认关闭,开启才发第一个网络请求(明示:说明文字写了 30 分钟一次)
- [ ] Open-Meteo(默认):开开关、城市留空 → 状态行约几秒后显示「晴 · xx°」等
- [ ] 填城市(如「北京」)→ 状态行城市跟着变
- [ ] 和风:数据源切「和风天气」→ 出现 Key/Host 两行 ⭐Key/Host 标签不再被输入框压住
  怎么验:切到和风,看 Key/Host 两行标签文字是否完整。
- [ ] 和风假 Key → 状态行显示失败原因(不崩溃、不弹窗),行为照常(静默降级)
- [ ] 雨天:鸟会躲雨/抖毛(hide/shiver 演出);大风/晴有对应倾向
  怎么验:看天吃饭;或者改代码里天气档位跑场景(懒人可跳过)。
- [ ] 天气状态行不贴底、不被裁 ⭐(本轮修复:状态行底部加了呼吸空间)

### 性能背书
- [ ] Mac:活动监视器里 KingfisherPet 常驻内存 < 60MB、CPU 空闲时 < 2%
- [ ] Win:日志有 PERF 行(任务管理器看内存/CPU 同上)

## 二、v1.5.1 素材 + 成长批(双端)

### 新演出
- [ ] 觅食(forage):鸟偶尔落地啄两下找食
- [ ] 躲雨/抖毛/炸毛(hide/shiver/puff):配合天气
- [ ] 喂鱼:托盘菜单「喂条鱼」→ 鸟叼鱼吞下(鱼从嘴尖竖直下垂像叼着)
- [ ] 小鸟来访(visitor):偶尔有 0.6× 小鸟飞来绕一圈走

### 亲密度系统
- [ ] 托盘菜单有 ❤ 亲密度状态行(档位名:陌生/相识/熟悉/亲近/亲密/缘定一生)
  怎么验:托盘菜单看 ❤ 行;点鸟/喂鱼后重开菜单看数值涨。
- [ ] 点鸟 +1(有日上限节奏)、喂鱼 +8(10 分钟冷却)、召唤 +2、自发捕鱼 +1
- [ ] 亲密度不随时间衰减
- [ ] 满级(缘定一生)触发一次性孵化彩蛋:下蛋 → 蛋摆着 → 小鸟绕飞告别
  怎么验:懒人路径——defaults 把亲密度写成 99 再点一下鸟(Mac:`defaults write com.hizml.kingfisher-pet kingfisher.growth.affection -int 99` 后重启)。
- [ ] 亲密度/喂鱼冷却重启不丢(持久化)

## 三、v1.6.0 分发批(双端)

### Mac 签名 + 公证(发版后验)
- [ ] 下载 Release 的 zip 解压,右键 → 显示简介:签名「Developer ID Application: …(5CTLSL2C9X)」
- [ ] 双击打开不被 Gatekeeper 拦(无「无法验证开发者」对话框)
- [ ] 终端跑 `spctl -a -vv /Applications/KingfisherPet.app` 显示 accepted/notarized

### Mac 应用内自动更新
- [ ] 托盘菜单「检查更新…」:当前已是最新 → 弹「已是最新版本」窗 ⭐按钮显示「好」而不是 update.ok(本轮修的 bug)
- [ ] 发新版后:菜单「检查更新…」→ 弹「发现新版本」→「下载并更新」→ 进度 → 自动重启进新版
- [ ] 更新失败(断网模拟)→ 弹失败窗,有「打开 Releases 页」按钮
- [ ] 旧版本被挪进废纸篓(可手动捞回 = 可回滚)

### Win 自动更新(Tauri)
- [ ] 设置里「检查更新」→ 有新版 → 下载进度条 → 自动重启进新版
- [ ] 失败时进度页有恢复按钮,不白屏
- [ ] 更新包验签:篡改的包会被拒(minisign)

### CI 加固(发版时自动验)
- [ ] tag 版本 ≠ 仓库三处版本号 → CI 直接红
- [ ] 单测不过 → 不出包
- [ ] 公证失败 → job 红,不出半成品
