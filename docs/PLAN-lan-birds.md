# 规划 · 局域网小鸟(串门批,候选 v1.7.0)

> 状态:规划稿,未立项开工。老板 2026-09-13 点名"规划一下,挺有意思"。
> 一句话:同一局域网里装了翡的电脑,鸟与鸟能发现彼此、对唱、串门、送鱼——
> 纯本地(Bonjour+TCP),无服务器无云,零账号。

---

## 1. 产品分期(每期独立可发,小步走)

### L1 对唱(观望期)——最小可用
- 设置新增「局域网小鸟」开关(默认关,明示纪律:开启后才广播自己)
- 发现同网段的翡 → 托盘状态行:「发现邻居:小绿的鸟」
- 鸟偶尔朝对方"方向"张望 + 两端音符特效同步对唱(各自屏幕各自渲染)
- 价值:零入侵的"有人在"感;工程上把发现/配对/协议全打通

### L2 串门(核心体验)
- 对方的鸟作为访客飞上我的屏幕:复用 VisitorService 航线演出,
  换成「邻居调色板」(按对方设备名 hash 从预设 N 套色相偏移里挑,读作"另一只鸟")
- 停留 ~3s 对唱 → 飞离;托盘菜单留下「今天 XX 的鸟来过」
- 互访有冷却(如 30 分钟),且**勿扰中不接客**(鸟隐身时访客也不来)
- 同时最多 1 只访客(视觉干净;多只留给 L4)

### L3 送鱼(社交闭环)
- 我的鸟叼鱼飞到屏边"寄出" → 对方鸟收到喂鱼演出 + 亲密度 +2(标注来源)
- 手动入口:菜单「给邻居送条鱼」;偶发自动(低概率)
- 亲密度联动:被送鱼当天加成上限内

### L4 鸟群(远期,看前几期水温)
- 双鸟同屏短暂散步/追逐;3 只以上"鸟群"编队飞过;本周访客统计

## 2. 协议草案(v1,双端一致,单测钉死)

```
传输:TCP, Bonjour 服务 _kingfisherpet._tcp.local,端口动态
     消息=换行分隔 JSON,带 v 字段;不认识的类型/版本静默丢弃
心跳:PING/PONG 5s;10s 无响应→判离线,演出中的访客自然飞走

HELLO    {v, name, theme}            建连自报家门(name=昵称,见 §4)
PEEP     {v, kind}                    对唱(单声/双声),收端播音符+叫声
VISIT    {v, dur}                     请求串门(收端排演出,拒绝则回 BUSY)
FISH     {v, from}                    送鱼(收端播喂鱼+亲密度+2)
BUSY     {v, reason}                  拒绝(dnd/冷却/已有访客)
BYE      {v}                          主动下线
```

纯函数部分(编解码/校验/冷却判定)进双端单测,口径同一份用例。

## 3. 双端实现要点

### Mac(Swift)
- 发现/监听:Network.framework `NWBrowser` + `NWListener`(系统级,零依赖,~200 行)
- 配对确认:KFDialog 自绘(发现新邻居 → 「允许 XX 的鸟来访吗?」允许/不再提示)
- 演出:VisitorService 已有三段式航线+池化窗,新增"邻居调色板"入参即可
- 接线:Behavior 新增 lanTick()(权重小,勿扰/锁屏/离屏全跳过)

### Windows(Tauri/Rust + TS)
- 发现:`mdns-sd` crate(纯 Rust,无 Bonjour SDK 依赖);TCP 用 std
- Rust 侧持连接,`emit` 事件到前端;演出走 poop 舞台 fx 通道(visitor 同款)
- 前端 behavior.ts 新增对应处理(与 Mac 同状态机语义)

### 素材
- gen_sprites 新增 `neighbor_palette(hash)` 预设 5 套色相偏移(90°/160°/210°/280°/330°),
  派生方式与 visitor_palette 同源;构建期全预生成,零运行时开销

## 4. 隐私与安全(红线先行)

- 默认关;开启才广播。广播内容只有:昵称 + 主题名,不含 IP/主机名/路径
- 昵称:设置可改;默认取系统名首段(如 "zhaomenglong的Mac" → "zhaomenglong"),
  允许用户改成 "小绿" 等
- 首次配对必须本机确认(允许一次/始终允许/拒绝);清单可管理(设置里移除)
- 只收白名单消息类型;消息长度上限 1KB;单 IP 连接数上限 3(防局域网内恶意灌包)
- 公司/公共 WiFi 常开 AP 隔离导致发现不到 → 文档明示"需同一路由器且未开客户端隔离"
