# 测试 · 翡 KingfisherPet

## 自动化(Mac,本机可跑)

```bash
./tools/run_tests.sh              # 全部场景
./tools/run_tests.sh sleepwake    # 单场景
```

场景与断言(结果写 `/tmp/kf_debug.log`,runner 汇总退出码):

| 场景 | 覆盖回归 | 关键断言 |
|---|---|---|
| `smoke` | 启动/破壳/状态机/窗口数 | 状态合法、常驻窗口 3-6、快照正立 |
| `sleepwave`(sleepwake) | **睡眠唤醒链路:静音/suspend/卡顿/树枝闪/屎雨** | 睡眠期 PetView suspend、唤醒后 `POOP refall`=0、苏醒完成 |
| `themecycle` | 6 主题资源完整性 | 每主题 frames=35 |
| `vis_toggle` | 隐藏/显示(死掉掉出/破壳)+ 幽灵特效 | 隐藏期窗口不可见+Effect=0,复活后状态合法 |

快照正立校验:像素级行宽签名(头窄在上=UPRIGHT;`FLIPPED` 即倒鸟回归)。

**加新场景**:在 `KingfisherPetApp.runTestScenario` 加 case,埋点用 `kfLog`,runner 里加专属断言(如有)。

**限制**:无真实鼠标/键盘注入(需要辅助功能权限,不做);系统睡眠/锁屏用 `systemWillSleep/systemDidWake` 直调模拟,等效时序。

## 手动回归清单(发版前,Mac + Windows 各过一遍)

> 自动化覆盖不了的部分。Windows 无本机运行时,**只能靠这份清单**。

1. **交互**:点击=害羞+叫;拖动跟手;拖到窗口上沿/任务栏附近松手→吸附;空中松手→飞走
2. **行为**:等 2 分钟,走(只在地面)/飞/捕鱼(悬停-俯冲-水花-叼鱼-吞)/唱(音符)/打盹(zzz)/日光浴/啄屏(裂纹,低概率)/停窗(跟随窗口移动,窗口关了飞走)
3. **屎**:吃完几秒后拉;落在窗口上沿;窗口移走屎重新掉;8 坨上限
4. **树枝**:悬空歇脚时**树枝先到**;窗口从脚下扫过树枝不闪
5. **主题**:切 6 个主题,鸟/阴影/树枝/屎/特效全跟;切完主题拉屎+裂纹还在(旧 v 的窗口重建炸)
6. **显示/隐藏**:隐藏=翻肚掉出;显示=破壳;隐藏状态锁屏一夜不耗电
7. **睡眠唤醒(重点)**:合盖 10 分钟→开盖:不卡、不叫、树枝稳、坐屎不动、鸟赖床几秒再醒
8. **托盘**:左键开菜单;各项可用;开机自启勾选状态正确
9. **多屏**(有条件):副屏拖鸟,屎/裂纹/特效在副屏可见
10. **连续运行 1 小时**:任务管理器 CPU <5%、内存平稳、窗口数不涨
11. **高 DPI(125%/150%,重点)**:飞/捕鱼全程在屏内不出右缘;阴影贴任务栏不悬空;屎落在窗口上沿(不落穿/落底);召唤过来时树枝正在脚下;拖拽吸附距离跟 100% 时手感一致

## 措辞纪律(对 AI 自己)

汇报"修完"必须附**验证方式**,三档明说:
- ✅ 编译过(tsc/swift/cargo,只保证语法)
- ✅ 场景过(run_tests.sh,保证时序行为)
- ✅ 快照过(像素校验,保证渲染)
- ⚠️ 仅推理(静态读码,**不算验证**)

"已知问题清零"≠"没有 bug";禁止把推理当验证汇报。
